# Denon DJ MC6000MK2 lamps, for JP24_Controller_Assignments.qml.
# Read by midisurface --led-map; midisurface.c describes the format:
#
#   <ch>:<note>  <ch> <on cc> <off cc> <lamp> [<dim lamp>]
#   send <ch> <cc> <value>
#
# The left side is the note Engine echoes to light a button, which is the note
# that button sends in the assignment file. The right side is the MC6000MK2's
# own lamp protocol: a Control Change whose number is the state and whose value
# is the lamp. Most lamps take 0x4A on / 0x4B off (and 0x4C to blink, unused:
# Engine blinks by itself). The CUE MIXER lamps take 0x50 on / 0x51 off.
#
# Lamp numbers are from the Mixxx mappings: Denon-MC6000MK2-scripts.js where it
# has them, and Denon-MC3000-scripts.js -- the same family, agreeing with the
# MK2 script on every lamp both list -- for PLAY, CUE, SYNC and HOT CUE. Lines
# marked "seen" were watched lighting on a real unit; the rest are still as
# read. HOT CUE has no dim lamp: 0x12, 0x14, 0x16 and 0x18 were tried as one
# and the buttons stayed dark.

# VINYL MODE is not in the table, and is held lit instead. On this unit the
# lamp is the mode: lit, the platter sends CC 0x51 and touch note 0x51, which
# is what the assignment file reads; dark, it sends CC 0x52 and note 0x56. The
# mapping uses the button for slip, and Engine blinking the lamp to say so
# switched the jog wheels off and on. So slip has no lamp.
send 1 0x4A 0x06
send 3 0x4A 0x06

# Left deck: DECK CHG. 3, MIDI channel 0x01.
1:0x43  1 0x4A 0x4B 0x27        # PLAY
1:0x42  1 0x4A 0x4B 0x26        # CUE
1:0x6B  1 0x4A 0x4B 0x09        # SYNC
1:0x06  1 0x4A 0x4B 0x08        # KEY LOCK (seen)
1:0x37  1 0x4A 0x4B 0x24 0x3E   # LOOP IN
1:0x39  1 0x4A 0x4B 0x40 0x2A   # LOOP OUT
1:0x1D  1 0x4A 0x4B 0x2B 0x53   # AUTO LOOP
1:0x17  1 0x4A 0x4B 0x11        # HOT CUE1, the first pad mode (seen)
1:0x18  1 0x4A 0x4B 0x13        # HOT CUE2
1:0x19  1 0x4A 0x4B 0x15        # HOT CUE3
1:0x20  1 0x4A 0x4B 0x17        # HOT CUE4

# Right deck: DECK CHG. 4, MIDI channel 0x03.
3:0x43  3 0x4A 0x4B 0x27        # PLAY
3:0x42  3 0x4A 0x4B 0x26        # CUE
3:0x6B  3 0x4A 0x4B 0x09        # SYNC
3:0x06  3 0x4A 0x4B 0x08        # KEY LOCK (seen)
3:0x37  3 0x4A 0x4B 0x24 0x3E   # LOOP IN
3:0x39  3 0x4A 0x4B 0x40 0x2A   # LOOP OUT
3:0x1D  3 0x4A 0x4B 0x2B 0x53   # AUTO LOOP
3:0x17  3 0x4A 0x4B 0x11        # HOT CUE1 (seen)
3:0x18  3 0x4A 0x4B 0x13        # HOT CUE2
3:0x19  3 0x4A 0x4B 0x15        # HOT CUE3
3:0x20  3 0x4A 0x4B 0x17        # HOT CUE4

# Pads: the SAMP. buttons, on each side's first channel like the notes they
# send. The full lamp is green and seen; the dim one is the other of the pair.
0:0x21  0 0x4A 0x4B 0x19 0x1A   # SAMP.1, left (seen)
0:0x22  0 0x4A 0x4B 0x1B 0x1C   # SAMP.2
0:0x23  0 0x4A 0x4B 0x1D 0x1F   # SAMP.3

2:0x23  2 0x4A 0x4B 0x1D 0x1F   # SAMP.3
2:0x24  2 0x4A 0x4B 0x20 0x21   # SAMP.4

# Mixer: CUE MIXER CH3 and CH4, Engine's channels 1 and 2.
0:0x05  0 0x50 0x51 0x51 0x52   # CUE MIXER CH3
0:0x07  0 0x50 0x51 0x57 0x58   # CUE MIXER CH4

# FILTER ON, the stem-levels switch. Lit while the strip's EQ knobs are stem
# levels. Driven as the CUE MIXER lamps are. The Mixxx MK2 script has these as
# 0x65 (left) and 0x66 (right), which lit neither on a real unit; the numbers
# here were found by lighting lamps one at a time and watching. 0x62, beside
# them, is the VIDEO lamp.
0:0x16  0 0x50 0x51 0x63        # FILTER ON (L) (seen)
0:0x1E  0 0x50 0x51 0x64        # FILTER ON (R) (seen)
